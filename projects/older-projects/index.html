Older Projects

I have not yet had the chance to make pages for some of my older projects. They are all accessible on my Github.

Some of note:

  • An ESP32 powered automatic light switcher which detects entry/exit to a room and can automatically flip the light switch on/off with the use of a servo motor. https://github.com/AaroSnid/Automatic-light-switcher
  • Many RISC-V projects, which include a program to output morse code strings by blinking an LED, and a program to measure and display a user's reaction time. https://github.com/AaroSnid/RISC-V-Projects
  • Some select VHDL projects, including a FSM controlled traffic light controller with integrated pedestrian crossing requests. https://github.com/AaroSnid/FPGA-Traffic-Light-Controller
  • An STM32 based alarm clock which, prior to an alarm going off, will activate an array of blue LEDs which can help the user wake more gracefully. https://github.com/AaroSnid/Alarm-Clock-with-Sunrise
